# Divya Rao — Portfolio (v2)

A redesign of [divya-portfolio](https://github.com/dsrao711/divya-portfolio), restyled in the spirit
of gracesportfolio.com — original HTML/CSS throughout, filled entirely with Divya's own case study
content, resume facts, and product screenshots.

## Structure

- `index.html` — home page (hero, work, skills, about, contact)
- `paid-collab.html` — full case study detail page for the Paid Collab project
- `images/` — case study creative thumbnails, product screenshots, and the hero illustration

## Local preview

No build step — just serve the folder:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/`.

## Deploy

Hosted on GitHub Pages from the `main` branch root.
